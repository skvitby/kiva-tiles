# Kiva — продающий сайт салона плитки (учебный кейс BA/SA)

Учебный проект для портфолио: от анализа конкурентов до работающего прототипа интернет-магазина керамической плитки для салона в Минске.

> ⚠️ Учебный прототип. Проект не заказан салоном Kiva и не связан с ним официально. Товары, цены и отзывы условные. Реальны только публичные данные: адрес, телефон и рейтинг с Яндекс.Карт.

- 🔗 **Живой сайт:** https://skvitby.github.io/kiva-tiles/site/
- 🔗 **Ранний прототип главной:** https://skvitby.github.io/kiva-tiles/prototype/
- 🔗 **Генератор постов (режим менеджера):** https://skvitby.github.io/kiva-tiles/site/?admin — откройте любой товар → «Пост для соцсетей»

## Задача

Спроектировать сайт, который продаёт плитку онлайн и приводит покупателей в шоурум. Посетитель должен выбирать плитку от задачи («ремонтирую ванную»), а не от артикула.

## Анализ конкурентов (Минск)

| Сайт | Сильные стороны | Слабые места |
|---|---|---|
| tileberry.by | Каталог по применению и текстурам, шоурум, проекты | Нет цен, корзины, отзывов |
| atrium.by | Цены, корзина, «купить в 1 клик», Outlet | Фильтр только по фактуре, нет интерьерных фото |
| dtls.by | Калькулятор, 3D-проект, каталог в мессенджер | Нет цен, корзины, фильтров |

**Решение:** навигация по задаче (как у tileberry), открытые цены и корзина (как у atrium), лид-магниты: калькулятор и 3D-проект (как у dtls). Плюс то, чего нет ни у кого из трёх: вид плитки в интерьере в карточке, допродажа клея и затирки, прогресс до бесплатной доставки.

## Ключевые решения на сайте

- **Вход по помещению**: крупные карточки «Ванная / Кухня / Пол…» сразу включают фильтр каталога.
- **Цена за м² и наличие** на каждой карточке, кнопка «+» добавляет товар без лишних шагов.
- **Карточка товара во всплывающем окне** (на телефоне — шторка снизу): галерея «плитка / крупно / в интерьере», характеристики, калькулятор с запасом на подрезку, «С этим берут».
- **Корзина**: прогресс до бесплатной доставки, изменение количества, оформление в два поля.
- **Честная срочность**: таймер с реальной датой окончания акции и реальный остаток в Outlet вместо выдуманного «осталось 2 шт.».
- **Мобильная версия**: нижняя панель «Каталог / Позвонить / Корзина».

## Генератор постов для SMM

**Задача.** Как SMM-менеджер салона, я хочу за минуту получить готовый пост о товаре по данным его карточки, чтобы не писать тексты для соцсетей с нуля.

**Как шла работа.** Исходный промпт ([`gen_post.md`](gen_post.md)) → ТЗ с User Story, AC и открытыми вопросами → решения с обоснованием → два кликабельных макета: отдельная вкладка или всплывающее окно ([`prototype/post-variants.html`](prototype/post-variants.html)) → выбрано окно поверх карточки товара → реализация. Финальное ТЗ — [`gen_post_v2.md`](gen_post_v2.md).

**Ключевые решения:**
- **JavaScript вместо Python** — сайт живёт на GitHub Pages, сервера нет.
- **Доступ по `?admin`** — инструмент для сотрудника, покупатель кнопку не видит.
- **Три площадки** (Instagram, Telegram, ВКонтакте) — у каждой свои длина, число эмодзи и хэштегов, CTA.
- **Стиль постов — только в [`site/voice.md`](site/voice.md)**: у каждой настройки комментарий, что она значит и какие значения допустимы. SMM-менеджер меняет тон и шаблоны без программиста.

## Технологии

HTML, CSS, JavaScript без фреймворков и сборки. Код прокомментирован, подробности в [`site/README.md`](site/README.md).

## Как запустить локально

Скачайте репозиторий и откройте `site/index.html` в браузере.

Генератору постов нужен локальный сервер: он загружает `voice.md`, а при открытии файла двойным кликом браузер это запрещает. Запустите Live Server в VS Code или выполните `python -m http.server` в папке `site` и откройте `http://localhost:8000/?admin`. Подробнее — в [`site/README.md`](site/README.md).
