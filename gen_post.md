Ты  - разработчик на phyton.

Создай интуитивно понятную, визуально приятную страницу — генератор постов для товара. 

Страница запускается в отдельном окне по нажатию на кнопку "Сформировать пость". Кнопка расположена на каждой карточке товара.

Важно: Без API, без баз данных, код простой и понятный для новичка.

Логика: пользователь открывает карточку товара и нажимает кнопку «Сформировать пост» — система собирает готовый текст по шаблону. 
Данные для поста берутся из текущей карточки товара.

Элементы в окне генерации поста:
 - поле для названия товара;
 - поле для описания товара (обязательное, со звёздочкой);
 - поле для цены или выгоды;
 - выбор настроения поста;
 - кнопка «Сформировать пост»;
 - блок «Готовый пост»;
 - кнопка «Скопировать пост» — после нажатия показывает сообщение «Пост скопирован».

Добавь файл voice.md с настройками стиля постов:
 - общий тон;
 - длина поста;
 - количество эмодзи;
 - силь заголовков;
 - стиль СТА;
 - правила для хэштегов;
 - чего избегать.
