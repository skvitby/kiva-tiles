# Стиль постов Kiva

Этот файл — единственное место, где задаётся стиль постов. Генератор постов на сайте (кнопка «Пост для соцсетей» в окне товара, режим `?admin`) читает настройки отсюда. Поменяли значение, сохранили, обновили страницу — посты стали другими. Код трогать не нужно.

Общее описание сайта — в [[README]].

## Как править

Настройки лежат в блоках, которые начинаются строкой ` ```settings имя `. Внутри блока одна строка — одна настройка:

```
ключ: значение   # комментарий
```

- **Слово после `settings`** (`general`, `instagram`, `expert` и т. д.) — имя блока. По нему генератор находит настройки. Не меняйте его.
- **Ключ** — слева от двоеточия. Тоже не меняйте.
- **Значение** — справа от двоеточия. Его можно менять.
- **Комментарий** — всё, что после `#`. Генератор его не читает, это подсказка для человека. Поэтому знак `#` в значениях не используйте: хэштеги пишутся без него.
- **Списки** — через запятую.

Чтобы изменения заработали, обновите страницу сайта.

## Подстановки в шаблонах

| Подстановка | Что вставится |
|---|---|
| `{name}` | Название товара из окна генератора |
| `{desc}` | Описание из окна генератора |
| `{price}` | Цена или выгода из окна генератора |
| `{brand}` | Фабрика |
| `{country}` | Страна производства |
| `{type}` | Материал (керамогранит, кафель…) |
| `{format}` | Размер плитки, см |
| `{e1}`, `{e2}`, `{e3}` | Места для эмодзи. Сколько заполнится — решает площадка, остальные места просто исчезнут |
| `{address}`, `{phone}` | Адрес и телефон салона (из общих настроек). Удобно для CTA |

Знак `|` в шаблоне — новый абзац.

## Общее

Действует для всех площадок и настроений.

```settings general
tags: плитка, плиткаминск, керамогранит, ремонт, интерьер, ремонтквартиры, дизайнинтерьера, ванная, kiva, минск   # хэштеги без знака #, через запятую, по важности; в пост попадают первые N — N задаёт площадка
stopwords: дёшево, дешёвый, самый лучший, лучший в мире, гарантированно, супер   # слова, которых не должно быть в посте; через запятую; если найдутся — генератор предупредит
address: Минск, пр-т Дзержинского, 131   # адрес салона; подставляется вместо {address}
phone: +375 29 778-09-20   # телефон салона; подставляется вместо {phone}
```

## Площадки

Чем площадки отличаются: в Instagram читают с телефона и ищут по хэштегам — пост короче, тегов больше. В Telegram читают длинное, хэштеги почти не нужны. ВКонтакте — между ними.

### Instagram

```settings instagram
length: 600   # лимит длины поста в символах; число, например 600 (Instagram принимает до 2200); если пост длиннее — счётчик станет красным
emoji: 3   # сколько мест {e1}–{e3} заполнить эмодзи; 0, 1, 2 или 3
hashtags: 8   # сколько хэштегов из общего списка tags добавить в конце; от 0 до числа тегов в списке
headline: обычный   # вид первого абзаца: «обычный» или «заглавные» (ВСЕ БУКВЫ ЗАГЛАВНЫЕ)
cta: Пишите в директ — подберём плитку под ваш интерьер   # призыв к действию в конце поста; любой текст, можно {address} и {phone}
```

### Telegram

```settings telegram
length: 900   # лимит длины поста в символах; число, например 900 (подпись к фото в Telegram — до 1024)
emoji: 2   # сколько мест {e1}–{e3} заполнить эмодзи; 0, 1, 2 или 3
hashtags: 3   # сколько хэштегов из общего списка tags добавить в конце; от 0 до числа тегов в списке
headline: обычный   # вид первого абзаца: «обычный» или «заглавные»
cta: Ждём в салоне: {address}. Телефон {phone}   # призыв к действию в конце поста; любой текст, можно {address} и {phone}
```

### ВКонтакте

```settings vk
length: 800   # лимит длины поста в символах; число, например 800
emoji: 2   # сколько мест {e1}–{e3} заполнить эмодзи; 0, 1, 2 или 3
hashtags: 5   # сколько хэштегов из общего списка tags добавить в конце; от 0 до числа тегов в списке
headline: заглавные   # вид первого абзаца: «обычный» или «заглавные»
cta: Оставьте заявку на сайте или позвоните: {phone}   # призыв к действию в конце поста; любой текст, можно {address} и {phone}
```

## Настроения

У каждого настроения — свой набор эмодзи и 2–3 шаблона. Генератор берёт шаблоны по очереди: повторное нажатие «Сформировать пост» даёт следующий. Шаблонов может быть сколько угодно — просто добавьте строку `template:`.

### Экспертное

Спокойно, по делу, факты о товаре. Без восклицательных знаков.

```settings expert
emoji: 📐, ✅, 🔍   # эмодзи для мест {e1}, {e2}, {e3}; через запятую, по порядку
template: {e1} {name} — {type} {format} см от фабрики {brand} ({country}) | {desc} | {e2} Цена: {price}   # шаблон поста; абзацы через |
template: Разбираем коллекцию {name} {e1} | Фабрика — {brand}, {country}. Формат — {format} см. | {desc} | {e2} {price}
template: На что смотреть при выборе плитки? Разберём на примере {name} {e3} | {desc} | {e2} {type}, {format} см — {price}
```

### Дружелюбное

Тепло, как совет знакомого. Обращение на «вы».

```settings friendly
emoji: 👋, 😊, 🏡   # эмодзи для мест {e1}, {e2}, {e3}; через запятую, по порядку
template: Знакомьтесь: {name} {e1} | {desc} | И всё это — {price} {e2}   # шаблон поста; абзацы через |
template: Ищете плитку, в которую влюбитесь с первого взгляда? {e1} | {name} от {brand}. {desc} | {e2} {price} {e3}
template: Немного уюта в вашу ленту {e3} | {name}. {desc} | {e1} Цена: {price}
```

### Акционное

Выгода в первой строке, ощущение «надо успеть». Только реальные цифры — без выдуманных «осталось 2 шт.».

```settings promo
emoji: 🔥, 💸, ⏰   # эмодзи для мест {e1}, {e2}, {e3}; через запятую, по порядку
template: {e1} Выгода на {name} | {price} | {desc} | {e3} Предложение ограничено по времени   # шаблон поста; абзацы через |
template: {e2} Успейте купить {name} по специальной цене | {desc} | {e1} {price}
```

### Вдохновляющее

Образ, настроение интерьера, меньше цифр.

```settings inspire
emoji: ✨, 🌿, 🤍   # эмодзи для мест {e1}, {e2}, {e3}; через запятую, по порядку
template: Дом начинается с деталей {e1} | {name} от {brand}. {desc} | {e2} {price}   # шаблон поста; абзацы через |
template: Представьте пространство, где всё дышит спокойствием {e1} | {name}. {desc} | {e3} {price}
template: Красивый ремонт — это не дорого, а продуманно {e2} | {name}. {desc} | {e1} {price}
```
