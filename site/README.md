# Kiva — сайт магазина плитки

Учебный прототип продающего сайта для салона плитки Kiva (Минск). Чистый HTML, CSS и JavaScript без фреймворков и сборки.
Карта сайта — в [[sitemap]].

## Как открыть

Дважды кликните `index.html`. Сайт откроется в браузере. Интернет нужен только для шрифтов.

Исключение — генератор постов: ему нужен сайт на GitHub Pages или локальный сервер (см. ниже).

## Из чего состоит

| Файл | Что внутри | Когда трогать |
|---|---|---|
| `index.html` | Разметка: все блоки страницы по порядку, у каждого комментарий с номером | Поменять тексты, добавить блок |
| `styles.css` | Внешний вид. В начале — переменные цветов и шрифтов | Поменять цвета, отступы, вид на телефоне |
| `products.js` | Товары, сопутствующие товары, названия помещений и текстур | Добавить или изменить товар |
| `script.js` | Поведение: фильтры, карточка товара, корзина, таймер, анимации | Изменить логику |
| `post.js` | Генератор постов для соцсетей: сборка, правка, Избранное | Изменить логику генератора |
| `telegram.js` | Публикация в Telegram-канал и очередь отложенных постов | Изменить публикацию или интервал проверки очереди |
| `voice.md` | Стиль постов: длина, эмодзи, хэштеги, CTA, шаблоны по площадкам и настроениям | Поменять тон и вид постов |

## Частые правки

**Поменять фирменный цвет.** В `styles.css`, раздел 1, поменяйте `--coral` (кнопки покупки), `--teal` (сервисы), `--sun` (акции).

**Добавить товар.** В `products.js` скопируйте любой блок `{ ... }` в массиве `PRODUCTS`, задайте новый `id` и свои значения. Товар сам появится в каталоге и фильтрах.

**Сделать товар уценённым (Outlet).** Укажите `outletLeft: 15` (остаток в м²), `oldPrice` и `badge: "sale"`.

**Вставить настоящие фото.** Сейчас текстуры нарисованы градиентами (классы `.tex-...` в `styles.css`, раздел 6). Положите фото в папку `img/` и замените, например:
```css
.tex-marble { background: url("img/marble.jpg") center / cover; }
```

**Порог бесплатной доставки** — `FREE_DELIVERY_FROM` в конце `products.js`.

## Генератор постов для соцсетей

Инструмент для SMM-менеджера: готовый пост о товаре по данным его карточки — за минуту.

**Как открыть.** Добавьте к адресу `?admin`, например `https://skvitby.github.io/kiva-tiles/site/?admin`. В окне товара появится кнопка «Пост для соцсетей». Обычные посетители кнопку не видят. Это скрытие, а не защита: для учебного прототипа достаточно.

**Как работает.** Поля заполняются из карточки товара, их можно править. Выберите площадку (Instagram, Telegram, ВКонтакте) и настроение, нажмите «Сформировать пост». Повторное нажатие даёт другой вариант текста. Генератор следит за длиной поста и предупреждает о стоп-словах. Закрытие окна возвращает в карточку товара.

**Правка поста.** Готовый текст можно править прямо в поле: счётчик символов и проверка стоп-слов обновляются при вводе. Если текст правили, «Сформировать пост» сначала спросит, заменить ли его.

**Избранное.** «☆ В избранное» сохраняет пост вместе с правками. Вкладка «Избранное»: открыть, скопировать, удалить. Пост, открытый из Избранного, можно править дальше — кнопка «★ Обновить в избранном» сохранит правки в ту же запись.

**Мои посты.** В режиме `?admin` в шапке есть кнопка «Мои посты» — открывает Избранное и очередь без выбора товара.

**Как поменять стиль постов.** Всё — в `voice.md`: лимиты длины, число эмодзи и хэштегов, CTA, шаблоны. У каждой настройки есть комментарий: что она значит и какие значения допустимы. Код трогать не нужно.

**Запуск на своём компьютере.** Генератор загружает `voice.md`, а при открытии файла двойным кликом браузер это запрещает. Варианты:
- VS Code → расширение Live Server → правый клик по `index.html` → Open with Live Server, затем добавьте `?admin` к адресу;
- или в папке `site` выполните `python -m http.server` и откройте `http://localhost:8000/?admin`.

Макеты, на которых выбирали вид генератора, — `../prototype/post-variants.html`. ТЗ доработок — `../gen_post_v3.md`.

## Публикация в Telegram

Пост можно отправить в Telegram-канал кнопкой «Опубликовать в Telegram» или запланировать на дату и время. Для этого нужен свой бот — он публикует посты от имени канала. Подключение — один раз, около 10 минут.

### Шаг 1. Создать канал
1. В Telegram: меню (☰ или карандаш) → «Создать канал».
2. Название, например «Kiva тест», описание — по желанию.
3. Тип канала: **публичный** — проще, адрес будет вида `@kiva_test_2026` (имя должно быть свободным, латиница, от 5 символов). Приватный тоже подойдёт, но понадобится числовой id (шаг 4).

### Шаг 2. Создать бота и получить токен
1. Найдите в поиске Telegram **@BotFather** (с синей галочкой) → «Start».
2. Отправьте `/newbot`.
3. Введите имя бота (его видно), например «Kiva посты».
4. Введите username — латиница, обязательно на `bot`, например `kiva_posts_bot`.
5. BotFather пришлёт **токен** — строку вида `1234567890:AAH...xyz`. Это пароль от бота: никому не отправляйте, в код и репозиторий не вставляйте. Если токен утёк — в @BotFather отправьте `/revoke`, выберите бота и получите новый.

### Шаг 3. Сделать бота админом канала
1. Откройте канал → название вверху → «Управление каналом» (или ✏️) → «Администраторы».
2. «Добавить администратора» → найдите бота по username.
3. Оставьте включённым право **«Публикация сообщений»**, остальные можно выключить → «Сохранить».

### Шаг 4. Узнать адрес канала
- **Публичный канал:** адрес — `@имя_канала`, например `@kiva_test_2026`. Можно вставить и ссылку `https://t.me/kiva_test_2026` — сайт сам превратит её в `@kiva_test_2026`.
- **Приватный канал:** нужен числовой id.
  1. Опубликуйте в канале любое сообщение.
  2. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` — свой токен, без угловых скобок).
  3. Найдите `"chat":{"id":-100…` — число вместе с минусом и есть id канала.

### Шаг 5. Подключить на сайте
1. Откройте сайт с `?admin`: https://skvitby.github.io/kiva-tiles/site/?admin
2. Любой товар → «Пост для соцсетей» → внизу окна «Настройки Telegram».
3. Вставьте токен и адрес канала → «Проверить подключение» → «Сохранить».
4. Сформируйте пост → «Опубликовать в Telegram» → проверьте пост в канале.

«Проверить подключение» подскажет, что не так: неверный токен, канал не найден или бот не админ канала.

### Где хранятся токен и посты
Токен, адрес канала, Избранное и очередь хранятся **только в этом браузере** (localStorage). В коде и репозитории их нет. В другом браузере или на другом компьютере их не будет — там настройки вводятся заново. На чужом компьютере после работы нажмите «Забыть токен».

### Отложенная публикация: важное ограничение
У ботов Telegram нет функции «опубликовать в указанное время», поэтому очередь проверяет сам сайт — раз в 30 секунд (`QUEUE_CHECK_EVERY` в `telegram.js`).
- Пост уйдёт, только если **в это время сайт открыт с `?admin`** — в любой вкладке, можно в фоне. В фоновой вкладке браузер может задержать публикацию примерно до минуты.
- Время — по часам компьютера.
- Если сайт был закрыт (или компьютер спал) и с назначенного времени прошло больше 5 минут (`MISSED_AFTER`), пост помечается «Пропущен» и **сам не уходит**: момент мог стать неактуальным, например акция уже закончилась. При следующем открытии сайта появится плашка «Не опубликовано вовремя» с кнопками «Опубликовать сейчас» и «Открыть очередь».
- Если открыто несколько вкладок, пост всё равно уйдёт один раз.

Надёжная альтернатива без открытой вкладки — серверный планировщик (например, Cloudflare Worker по расписанию). Для учебного прототипа он не нужен.

## Что сделано для продаж

| Приём | Где | Зачем |
|---|---|---|
| Цена за м² и наличие на карточке | Каталог | Покупатель не уходит звонить, чтобы узнать цену |
| Вход «по помещению» | Блок «Что ремонтируете?» и чипы фильтра | Человек ищет «плитку для ванной», а не артикул |
| «+» прямо на карточке | Каталог, Outlet | Добавить в один клик, без лишних шагов |
| Карточка товара во всплывающем окне | Клик по карточке | Подробности без ухода со страницы |
| Вид «в интерьере» | Галерея карточки | Снимает страх «а как это будет смотреться» |
| Калькулятор с запасом и ценой | Карточка товара | Отвечает на вопрос «сколько брать» и сразу кладёт нужное число коробок |
| «С этим берут» | Карточка товара | Допродажа клея и затирки, выше средний чек |
| Прогресс до бесплатной доставки | Корзина | Мотивирует добрать до порога |
| Таймер до конца акции | Верхняя полоса, Outlet | Акция с реальной датой окончания |
| Реальный остаток в м² | Outlet | Честное ограничение вместо выдуманного «осталось 2 шт.» |
| Купить в 1 клик | Карточка товара | Для тех, кому проще поговорить с менеджером |
| Рейтинг с Яндекс.Карт и отзывы | Блок отзывов | Доверие со стороны |
| Бесплатный 3D-проект | Первый экран, шаги, форма | Лид-магнит под крупный заказ |
| Нижняя панель на телефоне | Мобильная версия | Каталог, звонок и корзина всегда под пальцем |

## Ограничения прототипа

- Товары, цены, отзывы и режим работы — условные. Реальные только адрес, телефон и рейтинг с Яндекс.Карт.
- Формы никуда не отправляются, показывают сообщение (см. `script.js`, раздел 7).
- Корзина хранится только в браузере пользователя. Избранное, очередь постов и настройки Telegram — тоже.
- Вместо карты — заглушка.
