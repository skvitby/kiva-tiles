# Задача: генератор постов для товара (сайт Kiva)

> Черновик переписанного промпта из [[gen_post]]. Где ответа ещё нет — подставлены рекомендации. Финализировать после ответов на открытые вопросы (внизу).

## Роль и контекст
Ты — frontend-разработчик. Работаешь с существующим сайтом в `site/`
(HTML/CSS/JS без фреймворков, GitHub Pages). Сохраняй стиль кода и
дизайна сайта: те же цвета, шрифты, комментарии на русском.

## User Story
Как SMM-менеджер салона, я хочу за минуту получить готовый пост о товаре
по данным его карточки, чтобы не писать тексты для соцсетей с нуля.

## Ограничения
- Без API, сервера, баз данных и внешних библиотек.
- Код простой, понятный новичку; комментарии в местах, которые чаще всего меняют.
- Работает и на GitHub Pages, и при открытии файла двойным кликом.

## Точка входа
- В окне товара — кнопка «Пост для соцсетей».
- Открывает `post.html?id=<id товара>` в новой вкладке.

## Страница генератора (post.html)
Поля (предзаполнены из products.js по id, все редактируемые):
- Название товара — из `name`.
- Описание* (обязательное) — из `description`.
- Цена или выгода — из `price`; если есть `oldPrice` — «было X, стало Y».
- Настроение: экспертное / дружелюбное / акционное / вдохновляющее.

Кнопки и блоки:
- «Сформировать пост» → текст в блоке «Готовый пост».
- «Скопировать пост» → копирует текст, показывает «Пост скопирован».

## Логика генерации
- На каждое настроение 2–3 шаблона; повторное нажатие даёт другой вариант.
- Заголовок, эмодзи, CTA и хэштеги — по правилам из voice.js.

## Стиль постов
- `voice.md` — описание стиля для человека: тон, длина, количество эмодзи,
  стиль заголовков, стиль CTA, правила хэштегов, чего избегать.
- `voice.js` — те же параметры в коде; генератор берёт их отсюда.
  Комментарий в начале: «меняешь здесь — обнови voice.md».

## Acceptance Criteria
- Из окна любого товара открывается генератор с его данными.
- Без описания пост не формируется: поле подсвечено, есть подсказка.
- Разное настроение → заметно разный текст.
- Копирование работает; сообщение исчезает через 2–3 секунды.
- Страница удобна на телефоне (от 360px).

## Границы
- Новые файлы: post.html, post.js, voice.js, voice.md.
- В существующих — только добавить кнопку в окно товара.
- Обновить site/README.md: раздел про генератор.
