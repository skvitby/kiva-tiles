# Задача: генератор постов для товара (сайт Kiva)

> Переписанный промпт из [[gen_post]]. Все открытые вопросы закрыты — см. «Принятые решения» внизу.
> Макет выбранного варианта: `prototype/post-variants.html` (вариант Б).

## Роль и контекст
Ты — frontend-разработчик. Работаешь с существующим сайтом в `site/`
(HTML/CSS/JS без фреймворков, GitHub Pages). Сохраняй стиль кода и
дизайна сайта: те же цвета, шрифты, комментарии на русском.

## User Story
Как SMM-менеджер салона, я хочу за минуту получить готовый пост о товаре
по данным его карточки, чтобы не писать тексты для соцсетей с нуля.

## Ограничения
- Без API, сервера, баз данных и внешних библиотек.
- Код простой, понятный новичку; комментарии в местах, которые чаще всего меняют.
- Работает на GitHub Pages и через локальный сервер (Live Server в VS Code).
  При открытии файла двойным кликом генератор не работает: браузер не даёт
  загрузить `voice.md`. Это осознанное решение — описать в README.

## Точка входа
- Кнопка «Пост для соцсетей» в окне товара.
- Кнопка видна только по ссылке с `?admin` (например, `index.html?admin`).
  Это скрытие, а не защита — для учебного кейса достаточно.
- Кнопка открывает генератор во всплывающем окне поверх окна товара.

## Окно генератора
Поля (предзаполнены из products.js, все редактируемые):
- Название товара — из `name`.
- Описание* (обязательное) — из `description`.
- Цена или выгода — из `price`; если есть `oldPrice` — «было X, стало Y».
- Площадка: Instagram / Telegram / ВКонтакте (переключатель).
- Настроение: экспертное / дружелюбное / акционное / вдохновляющее.

Кнопки и блоки:
- «Сформировать пост» → текст в блоке «Готовый пост» + счётчик «N / лимит символов».
- «Скопировать пост» → копирует текст, показывает «Пост скопирован».
- Закрытие: ✕, «← к товару», клик по фону — возврат в окно товара.
  Esc закрывает только верхнее окно.
- На телефоне окно выезжает снизу на всю ширину, содержимое прокручивается.

## Логика генерации
- На каждое настроение 2–3 шаблона; повторное нажатие даёт другой вариант.
- Длина, эмодзи, хэштеги и CTA зависят от площадки — берутся из `voice.md`.
- Если `voice.md` не загрузился — понятное сообщение в окне вместо поста.

## Стиль постов — voice.md
Единственный источник настроек стиля. Для человека — обычный текст,
для генератора — блоки строгого формата:

````markdown
## Instagram
```settings
length: 600          # макс. длина поста в символах; число 200–2200
emoji: 3             # сколько эмодзи в посте; 0–6
hashtags: 8          # сколько хэштегов в конце; 0–30
address: нет         # обращение к читателю: «вы» / «ты» / «нет»
cta: Пишите в директ # призыв в конце поста; любой текст
```
````

- У каждой настройки — комментарий: что означает и какие значения допустимы.
- Блоки: по одному на площадку (Instagram, Telegram, ВКонтакте),
  по одному на настроение (шаблоны, эмодзи), общий (базовые хэштеги,
  стоп-слова, адрес салона).
- `post.js` читает файл через `fetch`, разбирает строки `ключ: значение  # комментарий`.

## Acceptance Criteria
- Без `?admin` кнопки «Пост для соцсетей» нет.
- С `?admin` из окна любого товара открывается генератор с его данными.
- Без описания пост не формируется: поле подсвечено, есть подсказка.
- Разное настроение → заметно разный текст; повторное нажатие → другой вариант.
- Разная площадка → разные длина, число эмодзи и хэштегов, CTA — по `voice.md`.
- Изменение значения в `voice.md` меняет пост без правки кода.
- Копирование работает; сообщение исчезает через 2–3 секунды.
- Закрытие генератора возвращает в окно товара.
- Окно удобно на телефоне (от 360px).

## Границы
- Новые файлы: `post.js`, `voice.md`.
- Существующие: `index.html` — разметка окна генератора; `script.js` —
  кнопка в окне товара и режим `?admin`; `styles.css` — стили окна.
- Обновить `site/README.md`: раздел про генератор, `?admin`, запуск через Live Server.

## Принятые решения
1. Язык — JavaScript (Python не работает на GitHub Pages без сервера).
2. Генератор — всплывающее окно поверх окна товара (сравнивали с отдельной вкладкой на макете).
3. Кнопка — только в окне товара.
4. Кнопку видит только менеджер — по ссылке с `?admin`.
5. Площадка — выбор из трёх: Instagram, Telegram, ВКонтакте.
6. Стиль — только `voice.md` с комментариями к каждой настройке; запуск двойным кликом не поддерживается.
