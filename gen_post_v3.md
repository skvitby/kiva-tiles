# Задача: доработки генератора постов (сайт Kiva)

> Доработки_1 из [[gen_post]]. Базовая функциональность — [[gen_post_v2]], её решения в силе,
> если ниже не сказано иное. Все открытые вопросы закрыты — см. «Принятые решения» внизу.

## Роль и контекст
Ты — frontend-разработчик. Дорабатываешь генератор постов в `site/`
(HTML/CSS/JS без фреймворков, GitHub Pages). Сохраняй стиль кода и
дизайна сайта, комментарии на русском, код понятный новичку.

## User Stories
1. **Редактирование.** Как SMM-менеджер, я хочу поправить готовый пост прямо в окне,
   чтобы не переносить текст в блокнот ради пары слов.
2. **Публикация в Telegram.** Как SMM-менеджер, я хочу отправить пост в Telegram-канал салона
   одной кнопкой, чтобы не копировать текст вручную.
3. **Отложенная публикация.** Как SMM-менеджер, я хочу запланировать пост на дату и время,
   чтобы готовить публикации заранее.
4. **Избранное.** Как SMM-менеджер, я хочу сохранять удачные посты,
   чтобы вернуться к ним позже и использовать повторно.

## Ограничения
- По-прежнему без своего сервера, баз данных и внешних библиотек.
- Единственный внешний вызов — Telegram Bot API (`https://api.telegram.org`) прямо из браузера.
  CORS открыт (`Access-Control-Allow-Origin: *`), работает и на Pages, и на Live Server.
- Все данные — только в браузере менеджера (`localStorage`): настройки Telegram, Избранное, очередь.
  На другом компьютере или в другом браузере их не будет. Это осознанное решение для учебного кейса.
- Токен бота **никогда** не попадает в код и репозиторий (репозиторий публичный).
- Telegram у ботов не умеет «опубликовать в указанное время» — отложенную публикацию
  выполняет сам сайт, поэтому вкладка должна быть открыта (см. раздел 3).

## 1. Редактирование поста
- Блок «Готовый пост» становится полем ввода (`textarea`), высота подстраивается под текст.
- При вводе пересчитываются счётчик «N / лимит символов» и предупреждения
  (стоп-слова, превышение лимита).
- «Скопировать», «В избранное», «Опубликовать» работают с текущим, отредактированным текстом.
- Если текст правили вручную, «Сформировать пост» сначала спрашивает:
  «Заменить отредактированный текст новым вариантом?» (Да / Отмена).

**AC**
- Правка текста сразу меняет счётчик; при превышении лимита счётчик красный.
- Скопированный текст = текст в поле, с правками.
- Повторная генерация после правки не стирает текст без подтверждения.

## 2. Публикация в Telegram

### Настройки Telegram
Сворачиваемый блок «Настройки Telegram» в окне генератора:
- **Токен бота** — поле-пароль (символы скрыты, кнопка «показать»).
- **Канал** — `@имя_канала` (публичный) или числовой id `-100…` (приватный).
- **«Проверить подключение»** — запросы `getMe` и `getChatMember`. Результат:
  «Бот @kiva_bot подключён к каналу „Kiva тест“» или понятная ошибка (таблица ниже).
- **«Сохранить»** — пишет настройки в `localStorage`; **«Забыть токен»** — удаляет их.
- Подсказка под полями: «Токен хранится только в этом браузере. Не сохраняйте его на чужом компьютере».

### Публикация
- Кнопка «Опубликовать в Telegram» под готовым постом.
- Пока настройки не заполнены, кнопка неактивна, рядом подсказка «Сначала заполните настройки Telegram».
- Перед отправкой — подтверждение: «Опубликовать пост в канал @имя?» (Да / Отмена).
- Отправка: `sendMessage`, обычный текст без разметки (`parse_mode` не используется —
  символы в тексте не сломают отправку).
- Успех → тост «Пост опубликован в канале»; ошибка → сообщение в окне, текст поста не теряется.

### Ошибки — понятным языком

| Ответ Telegram | Сообщение пользователю |
|---|---|
| 401 Unauthorized | Неверный токен бота. Скопируйте его из @BotFather ещё раз |
| 400 chat not found | Канал не найден. Проверьте адрес: `@имя_канала` или `-100…` |
| 403 / нет права публикации | Бот не админ канала или у него нет права «Публикация сообщений» |
| 400 message is too long | Пост длиннее 4096 символов — сократите текст |
| Нет сети | Нет связи с Telegram. Проверьте интернет и попробуйте ещё раз |
| Другое | Telegram ответил: «{description}» |

**AC**
- Без настроек опубликовать нельзя, подсказка видна.
- «Проверить подключение» различает: неверный токен / канал не найден / бот не админ / всё ок.
- После подтверждения пост появляется в канале с тем же текстом, что в поле.
- Токена нет в коде, репозитории и URL; после «Забыть токен» его нет в `localStorage`.

## 3. Отложенная публикация (вариант А — таймер в браузере)

### Как работает
- Рядом с «Опубликовать» — «Запланировать»: поле даты и времени (`datetime-local`), кнопка «В очередь».
- Время — по часам компьютера менеджера. Минимум — через 1 минуту от текущего момента.
- Очередь хранится в `localStorage`. Пока сайт открыт в режиме `?admin`,
  каждые 30 секунд проверяется, не пора ли отправить пост.
- Пост отправляется без повторного подтверждения — согласием считается постановка в очередь.
- Защита от дублей: если открыто несколько вкладок, пост отправляет только одна
  (блокировка записи в очереди перед отправкой).

### Пропущенные публикации
Если в назначенное время вкладка была закрыта (или компьютер спал):
- при следующем открытии сайта с `?admin` — плашка «Не опубликовано вовремя: N».
  Варианты: «Опубликовать сейчас» / «Открыть очередь».
- Автоматически пропущенные **не отправляются**: момент мог быть неактуален (например, акция уже кончилась).

### Очередь
Вкладка «Очередь» в окне генератора: товар, начало текста, дата и время, статус.

| Статус | Действия |
|---|---|
| Ожидает | Отменить |
| Пропущен | Опубликовать сейчас, Отменить |
| Ошибка (с текстом ошибки) | Повторить, Отменить |
| Опубликован (время) | Убрать из списка |

**AC**
- Нельзя запланировать на прошедшее время — поле подсвечено, есть подсказка.
- Пост из очереди публикуется в назначенную минуту (±30 сек), если вкладка открыта.
- Две открытые вкладки не публикуют один пост дважды.
- После закрытия и повторного открытия сайта пропущенные посты видны в плашке и в очереди, сами не уходят.
- Отменённый пост не публикуется.

**Известное ограничение (в README):** вкладка с сайтом должна быть открыта в момент публикации.
Надёжная альтернатива — серверный планировщик (например, Cloudflare Worker по расписанию) —
вне рамок учебного кейса.

## 4. Избранное
- Кнопка «☆ В избранное» под готовым постом. Сохраняется: текст (с правками), товар,
  площадка, настроение, дата сохранения.
- Вкладка «Избранное (N)» в окне генератора: список карточек — товар, площадка,
  дата, первые 2 строки текста.
- Действия с карточкой: «Открыть» (текст попадает в поле готового поста, площадка переключается),
  «Скопировать», «Удалить» (с подтверждением).
- Если пост открыт из Избранного, кнопка становится «Обновить в избранном» — правки
  сохраняются в ту же запись, а не создают копию.
- Пустое Избранное: «Здесь появятся сохранённые посты».

**AC**
- Сохранённый пост остаётся после перезагрузки страницы.
- «Открыть» → текст в поле, можно править, копировать, публиковать, планировать.
- «Обновить в избранном» не создаёт дубль.
- Удаление спрашивает подтверждение.

## Окно генератора после доработок
Вкладки сверху: **Новый пост** · **Избранное (N)** · **Очередь (N)**.

«Новый пост»: поля как в v2 → «Сформировать пост» → поле готового поста →
строка кнопок: Скопировать · ☆ В избранное · Опубликовать в Telegram · Запланировать →
сворачиваемый блок «Настройки Telegram».

На телефоне (от 360px) кнопки переносятся в две строки, вкладки остаются в одну строку.

## Границы
- `post.js` — вся логика: редактирование, Telegram, очередь, Избранное. Разделить на пронумерованные
  блоки, как сейчас; если файл станет больше ~450 строк — вынести Telegram и очередь в `telegram.js`.
- `index.html` — вкладки, поле поста, кнопки, настройки Telegram, плашка пропущенных.
- `script.js` — запуск проверки очереди и плашки только в режиме `?admin`.
- `styles.css` — стили вкладок, карточек, статусов, плашки.
- `site/README.md` — инструкция по подключению Telegram (Приложение), ограничение таймера,
  где хранятся данные.
- `voice.md` не меняется.

## Вне рамок
- Публикация с фото товара (`sendPhoto`) — возможна позже, лимит подписи 1024 символа.
- Публикация в Instagram и ВКонтакте.
- Синхронизация Избранного и очереди между устройствами.

## Принятые решения
1. Отложенная публикация — таймер в браузере (вариант А). Серверный планировщик (Cloudflare Worker) —
   вне рамок: надёжнее, но требует регистрации и серверного кода.
2. Токен бота и адрес канала — в `localStorage` браузера менеджера, не в коде.
3. Избранное и очередь открываются кнопкой «Мои посты» в шапке (только `?admin`) — сразу на вкладке
   «Очередь». Уточняет решение 3 из v2: кнопка генератора по-прежнему только в окне товара.
4. Пост, собранный для Instagram/ВКонтакте, публиковать в Telegram можно — с предупреждением
   «Пост собран для Instagram — длина и хэштеги могут не подойти Telegram».
5. Пропущенные публикации сами не уходят — только по кнопке «Опубликовать сейчас».
6. Логика Telegram и очереди вынесена в `telegram.js`, генератор и Избранное — в `post.js`.

## Приложение. Как подключить Telegram-канал (простыми словами)

**Что понадобится:** канал, бот, токен бота и адрес канала. Займёт ~10 минут.

### Шаг 1. Создать канал
1. В Telegram: меню (☰ или карандаш) → «Создать канал».
2. Название, например «Kiva тест», описание — по желанию.
3. Тип канала: **публичный** — проще, адрес будет вида `@kiva_test_2026`
   (имя должно быть свободным, латиница, от 5 символов).
   Приватный тоже подойдёт, но понадобится числовой id (шаг 4).

### Шаг 2. Создать бота и получить токен
1. Найти в поиске Telegram **@BotFather** (с синей галочкой) → «Start».
2. Отправить `/newbot`.
3. Ввести имя бота (видно подписчикам), например «Kiva посты».
4. Ввести username — латиница, обязательно на `bot`, например `kiva_posts_bot`.
5. BotFather пришлёт **токен** — строку вида `1234567890:AAH...xyz`. Это пароль от бота:
   никому не отправлять, в код и репозиторий не вставлять.
   Если токен утёк — в @BotFather: `/revoke` → выбрать бота → получить новый.

### Шаг 3. Сделать бота админом канала
1. Открыть канал → название вверху → «Управление каналом» (или ✏️) → «Администраторы».
2. «Добавить администратора» → найти бота по username.
3. Оставить включённым право **«Публикация сообщений»**, остальные можно выключить → «Сохранить».

### Шаг 4. Узнать адрес канала
- **Публичный канал:** адрес — `@имя_канала`, например `@kiva_test_2026`.
- **Приватный канал:** нужен числовой id.
  1. Опубликовать в канале любое сообщение.
  2. Открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
     (вместо `<ТОКЕН>` — свой токен, без угловых скобок).
  3. Найти `"chat":{"id":-100…` — число вместе с минусом и есть id канала.

### Шаг 5. Подключить на сайте
1. Открыть сайт с `?admin`: https://skvitby.github.io/kiva-tiles/site/?admin
2. Любой товар → «Пост для соцсетей» → «Настройки Telegram».
3. Вставить токен и адрес канала → «Проверить подключение» → «Сохранить».
4. Сформировать пост → «Опубликовать в Telegram» → проверить пост в канале.
